Desafio Aceito

Aplicativo: Desafio Aceito, projeto acadêmico da FECAP (Ciência da Computação) desenvolvido pela equipe FutTech. O app ajuda equipes amadoras de futebol a encontrar adversários e combinar partidas.

Última atualização: 15 de novembro de 2026.

Dados que coletamos

  • Conta: e-mail e senha (a senha é guardada apenas como hash irreversível).
  • Dados do time: nome, cidade, categoria, horários, mensagens de chat e partidas que você cadastra no app.

Como usamos

Os dados servem apenas para autenticar você, mostrar seu time a outras equipes e organizar partidas. Não vendemos, não compartilhamos com terceiros para publicidade e não usamos para criar perfis de anúncio.

Armazenamento

Os dados ficam em servidor com banco de dados PostgreSQL. Trata-se de um projeto acadêmico; os dados podem ser apagados ao fim da avaliação.
